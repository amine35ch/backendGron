Documentation API GRON - Routes Fiables

Cette documentation ne présente que les endpoints API considérés comme fiables et bien documentés.

À propos de cette documentation

Pour améliorer la qualité et la fiabilité de notre documentation d'API, nous avons choisi de limiter la documentation aux endpoints qui sont:

  • Fiables: Ces endpoints ont été testés et sont considérés comme stables.
  • Bien documentés: Ils incluent des descriptions complètes, des exemples de requêtes et de réponses.
  • Actuels: Les endpoints dépréciés ou obsolètes ont été exclus.
